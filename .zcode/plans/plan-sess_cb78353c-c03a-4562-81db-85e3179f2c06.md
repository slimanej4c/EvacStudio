# Plan : Ajout d'outils texte sur le plan (taille, police, couleur + fond optionnel)

## Vue d'ensemble

Ajouter une fonctionnalité d'insertion de **texte** sur le plan d'évacuation, sur le même modèle que les icônes et formes existantes. Les textes sont **persistants en DB**, avec contrôle de : **contenu, police, taille, couleur du texte, et fond coloré optionnel**. Ils sont automatiquement inclus dans l'export PNG/PDF (car rendus dans le layer `planSheet` de Konva).

## 1. Backend — Modèle `PlanText`

**Fichier : `backend/evacuation_plans/models.py`** (après `PlanShape`, ~ligne 124)

Nouveau modèle `PlanText` avec FK vers `EvacuationPlan` (`related_name='texts'`, CASCADE), champs :
- `text` : TextField (contenu, multi-ligne possible)
- `x`, `y` : FloatField (position)
- `font_size` : FloatField (défaut 24)
- `font_family` : CharField(max_length=64, défaut `'Arial'`)
- `color` : CharField(max_length=16, défaut `'#000000'`)
- `bold` : BooleanField (défaut False)
- `italic` : BooleanField (défaut False)
- `background_color` : CharField(max_length=16, null=True, blank=True) — si null, pas de fond
- `rotation` : FloatField (défaut 0.0)
- `created_at`, `updated_at`

## Points d'attention

- **Export** : aucun code supplémentaire nécessaire, les nœuds Konva dans `planSheet` sont capturés par `stage.toDataURL` existant (ligne 1829).
- **Transformer unidimensionnel** : le redimensionnement d'un texte mettra à jour `font_size` via `scaleX` (transformé en nouvelle taille de police), pas la width/height.
- **Sélection croisée** : un seul élément sélectionnable à la fois (icône OU forme OU texte), cohérent avec le pattern existant.
- **Police** : seules des polices web-safe seront proposées (pas de chargement de fonts externe) pour rester léger et fiable à l'export.
- **Robustesse backend** : `sync_texts` utilisera le pattern robuste (transaction + bulk_create + validation serializer), contrairement au `sync_icons` actuel qui est fragile.
